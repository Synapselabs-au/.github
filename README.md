# Synapse Labs organisation profile

This is the special public repository for [Synapse Labs](https://synapselabs.com.au)
on GitHub. GitHub displays [profile/README.md](profile/README.md) on the
organisation page.

It provides GitHub-supported default community health files for public
repositories:

- [Contributing guidelines](CONTRIBUTING.md)
- [Code of Conduct](CODE_OF_CONDUCT.md)
- [Security policy](SECURITY.md)

The [GitHub Actions and protected delivery policy](WORKFLOW_POLICY.md) is the
organisation's human-readable source policy. GitHub does not distribute or
enforce that custom file automatically; repository settings and local guidance
implement it through the adoption inventory in the policy.

[Jordan Fuller](mailto:jordan@synapselabs.com.au).
