# Contributing to Synapse Labs repositories

Thank you for taking the time to contribute. Before starting substantial work,
open an issue or contact the repository maintainers so the proposed change can
be discussed in context.

## Pull requests

- Keep each pull request focused on one clear change.
- Explain what changed, why it is needed, and how you verified it.
- Add or update tests when behaviour changes.
- Do not include secrets, personal data, generated build output, or unrelated
  formatting changes.
- Follow the repository's own development instructions when they are present.

All contributions are reviewed before merging. By participating, you agree to
follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Questions

For questions that are not appropriate for a public issue, email
[jordan@synapselabs.com.au](mailto:jordan@synapselabs.com.au).
